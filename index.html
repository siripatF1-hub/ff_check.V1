ใช้ตรวจหมวดและอัตราค่าใช้จ่ายรายรายการ (หัวตาราง "รหัสรายการ" "หมวด" "งบประมาณของรายการ")

1 · เป็นโครงการวิจัยและพัฒนานวัตกรรมตามพันธกิจ

คัดกรองจากคำในชื่อ วัตถุประสงค์ ผลผลิต และคำสำคัญ เทียบกับเป้าประสงค์และยุทธศาสตร์หน่วยงาน ผู้ตรวจควรอ่านยืนยันรายการ "ควรทบทวน" และ "ไม่ผ่าน" ก่อนแจ้งหน่วยงาน

        ผลสำหรับกรอกกลับชีตตรวจคำขอ

        ค่า Y/N เป็นข้อเสนอจากระบบ ผู้ตรวจควรทบทวนก่อนวาง ปุ่มคัดลอกจะคัดลอกทุกแถวตั้งแต่แถวแรกของข้อมูลเรียงตรงกับแถวในไฟล์ (แถวแผนงานและหน่วยงานเป็นช่องว่าง) เลือกเซลล์ตามที่ระบุในไฟล์ต้นฉบับแล้ววาง

        ร่างข้อสังเกตถึงหน่วยงาน

        แก้ไขข้อความในกล่องได้โดยตรง กด "สร้างร่างใหม่" เมื่อเปลี่ยนไฟล์หรือการตั้งค่า (ข้อความที่แก้เองจะถูกแทนที่)

        ตรรกะการตรวจ

        การอ่านไฟล์

        • หาแถวหัวตารางจากเซลล์ "รหัสแผนงาน/โครงการ" แล้วจับคู่คอลัมน์จากข้อความหัวตาราง จึงยังอ่านได้แม้ลำดับคอลัมน์เปลี่ยน
        • แถวไม่มีรหัสแต่มีงบ = แถวรวมหน่วยงาน · แถวมีรหัสและมีงบแผนงาน = แผนงาน (ถ้ามีกรอบงบหรือชื่อขึ้นต้น "แผนงานเสริมสร้างความเข้มแข็ง" = แผนเสริมสร้างฯ) · แถวมีรหัสแต่ไม่มีงบแผนงาน = โครงการภายใต้แผนงานที่อยู่ก่อนหน้า
        • ปีงบประมาณอ่านจากหัวตาราง "งบ...ปี 70" และแก้ได้ในช่องปีงบประมาณ

        ด้าน 1 · งานวิจัยตามพันธกิจ (2.4, 2.5)

        • คำพันธกิจ = คำสำคัญของโครงการในหน่วยงานที่ปรากฏในเป้าประสงค์/ยุทธศาสตร์หน่วยงาน (ตัดคำทั่วไป เช่น นวัตกรรม วิจัย) รวมกับคำที่ผู้ตรวจเพิ่ม · 2.4 = Y เมื่อพบคำพันธกิจในชื่อ วัตถุประสงค์ ผลผลิต หรือคำสำคัญ
        • ไม่ผ่าน พบคำบ่งชี้งานไม่ใช่วิจัย (อบรม สัมมนา ก่อสร้าง จัดซื้อ จ้างเหมา บริการวิชาการ ฯลฯ) และคำบ่งชี้งานวิจัยน้อยกว่า 2 คำ · 2.5 = N เฉพาะกรณีนี้

        ด้าน 2 · ความซ้ำซ้อน (2.6)

        • เทียบทุกคู่โครงการด้วย character trigram (Dice) ของชื่อ และของชื่อ+วัตถุประสงค์+คำสำคัญ ตัดคำทั่วไปและ trigram ที่พบในเกินครึ่งของโครงการในหน่วยงาน (เช่น "พื้นที่สูง") เพื่อไม่ให้ทุกโครงการคล้ายกันเพราะบริบทเดียวกัน
        • ≥ 0.60 ซ้ำซ้อนสูง (2.6 = Y) · 0.45–0.59 ควรตรวจสอบ · เทียบกับรายชื่อโครงการเดิมที่ผู้ตรวจใส่ · เตือนเมื่อระบุว่ายื่นแหล่งทุนอื่น หรือหัวหน้าคนเดียวมากกว่า 3 โครงการ

        ด้าน 3 · สัดส่วนงบประมาณ

        • งบเสนอขอรวม T = ผลรวมงบแผนงานวิจัยและนวัตกรรม + งบแผนเสริมสร้างฯ (ปิดได้ด้วยตัวเลือกด้านบน) · ตัวเศษรวมจากแถวโครงการ (และแผนเสริมสร้างฯ เมื่อนับรวม)
        • ค่าจ้าง ≤ 30% · สาธารณูปโภค ≤ 1% · ซ่อมแซมครุภัณฑ์/สอบเทียบ ≤ 10% · ครุภัณฑ์ ≤ 20% · ซ่อมแซม + ครุภัณฑ์ ≤ 20% · ต่างประเทศ 5% / 4% / 3% และ ≤ 20 ลบ. ตามวงเงิน (25 ลบ. พอดีนับเป็นช่วง 25–150) · เสริมสร้างฯ ≤ 5% และ ≤ 5 ลบ.
        • ยอดที่ต้องลดขั้นต่ำ r = (A − pT) / (1 − p) เพราะการลดหมวดใดทำให้ T ลดด้วย ถ้ามีเพดานเป็นเงิน C ใช้ค่าที่มากกว่าระหว่าง r กับ A − C

        ด้าน 4 · ยอดงบแผนงาน โครงการ และกรอบงบประมาณ

        • งบประมาณของแผนงาน = ผลรวมงบเสนอขอของโครงการภายใต้แผนงานนั้น ทั้งยอดรวมและรายหมวด
        • ผลรวมงบทุกแผนงาน รวมแผนเสริมสร้างฯ = กรอบงบประมาณที่ สกสว. แจ้ง ต้องเท่ากันพอดี (ค่าเริ่มต้นคือกรอบงบวิจัยฯ ในแถวหน่วยงาน + กรอบแผนเสริมสร้างฯ จากไฟล์ แก้ได้ในช่องกรอบงบประมาณ)
        • ยอดระดับหน่วยงานเท่ากับผลรวมแผนงาน, ช่อง Y Z AA ต้องตรงกัน, ผลรวมรายหมวดเท่ากับยอดรวม, ผลรวมโครงการ MY

        ด้าน 5 · หมวดและอัตราค่าใช้จ่ายรายรายการ (อ้างอิงคู่มือ FF บทที่ 2)

        • รวมรายการตามรหัสโครงการ ใช้เฉพาะรายการของ "ปีที่" = ปีงบประมาณ − ปีเริ่ม + 1 แล้วเทียบกับงบเสนอขอและงบรายหมวดในไฟล์ตรวจคำขอ
        • ผิดหมวด: สิ่งของคงทน (เครื่องคอมพิวเตอร์ โน้ตบุ๊ก แท็บเล็ต เครื่องพิมพ์ กล้อง เครื่องชั่ง ตู้เย็น ฯลฯ) ในค่าวัสดุ → ค่าครุภัณฑ์ (ข้อ 1.3, 1.4) · วัสดุคอมพิวเตอร์/โปรแกรมราคาต่อหน่วยเกิน 20,000 บาท → ค่าครุภัณฑ์ (ข้อ 1.3 (9)(10)) · ซ่อม/บำรุงรักษา/สอบเทียบในค่าใช้สอย → ค่าซ่อมแซมครุภัณฑ์ (ข้อ 1.2 (22)) · จ้างเหมา/บริการในหมวดค่าจ้าง → ค่าใช้สอย (ข้อ 1.1) · ค่าก่อสร้าง/ปรับปรุงสิ่งก่อสร้างไม่สนับสนุน · ครุภัณฑ์คอมพิวเตอร์/โปรแกรมต้องใช้เพื่อการคำนวณขั้นสูงหรือข้อมูลปริมาณมาก (ข้อ 1.4 (6)) · รายละเอียดไม่ตรงหมวดย่อย
        • อัตรา: ค่าจ้าง ป.เอก 30,000 / ป.โท 25,000 / ป.ตรี 18,000 / ปวส. 12,500 / ปวช. 11,000 บาทต่อเดือน · OT วันทำการ 50 บาท/ชม. ไม่เกิน 4 ชม. วันหยุด 60 บาท/ชม. ไม่เกิน 7 ชม. · วิทยากร ≤ 1,200 บาท/ชม. · เบี้ยเลี้ยง ≤ 400 บาท/วัน · ที่พัก ≤ 2,000 บาท/คืน · อาหารประชุม ≤ 1,000 บาท/วัน/คน · รถพร้อมคนขับ ≤ 2,500 บาท/วัน · รถยนต์ ≤ 6 บาท/กม. · ต่างประเทศ เบี้ยเลี้ยง ≤ 2,500 บาท/วัน ที่พัก ≤ 10,500 บาท/คืน (ตรวจได้เมื่อหน่วยนับเป็นวันหรือคืน มิฉะนั้นแจ้งให้แสดงจำนวนวัน)
        • แผนเสริมสร้างฯ ไม่สนับสนุนครุภัณฑ์ ค่าเดินทางต่างประเทศ ค่าพัฒนาระบบสารสนเทศใหม่ และค่าประเมินผลลัพธ์/ผลกระทบ (ข้อ 2.5) · ตัวคูณ จำนวน × คน × ครั้ง × ราคา ต้องเท่ากับงบของรายการ · รายการซ้ำ (หมวด หมวดย่อย และรายละเอียดเดียวกัน)

        ด้าน 6 · ความครบถ้วนและถูกต้อง

        • ปีและระยะเวลา: โครงการใหม่เริ่มปีที่เสนอขอ, ต่อเนื่องเริ่มก่อน, ระยะเวลา = ปีสิ้นสุด − ปีเริ่ม + 1, MY สอดคล้องกับระยะเวลา, ต่อเนื่องควรระบุรหัส/ชื่อปีก่อน
        • ช่องบังคับของโครงการ, ยุทธศาสตร์ ววน. 1–4 ของแผนงาน, สังกัดหัวหน้าโครงการต้องเป็นหน่วยงานที่ยื่น, ข้อความที่มีแท็ก HTML ปน
        • ครุภัณฑ์: มีงบต้องมีชื่อรายการและข้อมูลใบเสนอราคา 3 ราย, ครุภัณฑ์ประเภทจัดจ้างทำได้เฉพาะฐานข้อมูล แอปพลิเคชัน เว็บไซต์ · ค่าเดินทางต่างประเทศเกินร้อยละ 20 ของงบโครงการให้ชี้แจง
