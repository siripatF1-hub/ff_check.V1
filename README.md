# ระบบตรวจคำของบประมาณ FF

เครื่องมือช่วยเจ้าหน้าที่ สกสว. ตรวจคำของบประมาณกองทุนส่งเสริม ววน. ด้านการสนับสนุนงานมูลฐาน (Fundamental Fund; FF) ที่หน่วยงานเสนอผ่านระบบ NRIIS และร่างข้อสังเกตแจ้งหน่วยงานให้ปรับปรุงคำขอ

**เปิดใช้งาน:** https://siripatf1-hub.github.io/ff_check.V1/

## วิธีใช้

1. เปิดลิงก์ด้านบนด้วย Chrome หรือ Edge (ต้องต่ออินเทอร์เน็ต เพราะตัวอ่าน Excel โหลดจาก CDN)
2. อัปโหลดไฟล์ Excel 2 ไฟล์ จะกดปุ่มเลือกไฟล์หรือลากมาวางในหน้าก็ได้ ระบบแยกประเภทไฟล์จากหัวตารางให้เอง
   - **ไฟล์ตรวจคำขอ (แผนงาน-โครงการ)** ชีตที่มีหัวตาราง "รหัสแผนงาน/โครงการ" (จำเป็น)
   - **ไฟล์รายการค่าใช้จ่าย** ชีตที่มีหัวตาราง "รหัสโครงการ" "หมวด" "งบประมาณของรายการ" (ไม่บังคับ ใช้ตรวจข้อ 5)
3. ตรวจค่าตั้งต้น ได้แก่ ปีงบประมาณ กำหนดส่งคำขอฉบับปรับปรุง และ**กรอบงบประมาณตามหนังสือแจ้งของ สกสว.** (ถ้าเว้นว่าง ระบบใช้คอลัมน์กรอบงบในไฟล์ตรวจคำขอ)
4. ดูผลในแท็บ "ผลการตรวจ" แล้วคัดลอกผลไปใช้จากแท็บ "กรอกกลับชีต" และ "ร่างข้อสังเกต"

ไฟล์ที่อัปโหลดถูกอ่านในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ใด

## การตรวจ 6 ด้าน

| ด้าน | สิ่งที่ตรวจ |
|---|---|
| 1. งานวิจัยตามพันธกิจ | คำบ่งชี้งานวิจัยและงานที่ไม่ใช่วิจัยในชื่อ วัตถุประสงค์ ผลผลิต เทียบคำสำคัญกับเป้าประสงค์และยุทธศาสตร์หน่วยงาน (เสนอค่า 2.4 และ 2.5) |
| 2. ความซ้ำซ้อน | ความคล้ายของชื่อ วัตถุประสงค์ และคำสำคัญระหว่างโครงการ (character trigram) และกับรายชื่อโครงการเดิม (เสนอค่า 2.6) |
| 3. สัดส่วนงบตามเกณฑ์ กสว. | ค่าจ้าง ≤ 30% · สาธารณูปโภค ≤ 1% · ซ่อมแซม/สอบเทียบ ≤ 10% · ครุภัณฑ์ ≤ 20% · ซ่อมแซม + ครุภัณฑ์ ≤ 20% · ต่างประเทศ 5% / 4% / 3% (≤ 20 ลบ.) ตามวงเงิน · เสริมสร้างฯ ≤ 5% และ ≤ 5 ลบ. |
| 4. ยอดงบและกรอบงบ | งบแผนงาน = ผลรวมงบโครงการภายใต้แผน (ยอดรวมและรายหมวด) · งบทุกแผนงานรวมแผนเสริมสร้างฯ = กรอบงบที่ สกสว. แจ้ง |
| 5. หมวดและอัตราค่าใช้จ่าย | การจัดหมวดผิด อัตราเกินเกณฑ์ ตัวคูณ และรายการซ้ำ อ้างอิงคู่มือการจัดทำคำของบประมาณ FF บทที่ 2 |
| 6. ความครบถ้วนและถูกต้อง | ช่องบังคับ ปีเริ่ม/สิ้นสุด ระยะเวลา MY สังกัดหัวหน้าโครงการ ข้อมูลครุภัณฑ์และใบเสนอราคา |

รายละเอียดเกณฑ์และค่าตัดสินทั้งหมดอยู่ในแท็บ "ตรรกะการตรวจ" ในหน้าระบบ

## ข้อจำกัด

- ด้าน 1, 2 และการตรวจผิดหมวดในด้าน 5 ใช้คำสำคัญและความคล้ายของข้อความ เป็นการคัดกรองเบื้องต้น ผู้ตรวจควรยืนยันก่อนแจ้งหน่วยงาน
- อัตราค่าใช้จ่ายตรวจได้เมื่อหน่วยนับระบุเป็นวัน คืน ชั่วโมง หรือกิโลเมตร ถ้าระบุเป็น "ครั้ง" ระบบจะแจ้งให้แสดงจำนวนวันแทน
- ผลการตรวจแต่ละด้านเป็นข้อเสนอให้ผู้ตรวจพิจารณา ไม่ใช่ผลการพิจารณาอย่างเป็นทางการ
